# ⚡ TONYMIC Cyberpunk Workstation Dotfiles

A complete, high-performance **Cyberpunk Netrunner** terminal and editor aesthetic suite built for **Fish Shell**, **Starship**, and **VS Code / Windsurf / Devin** editors.

## ✨ Features

- **Cross-Platform Fish Shell (`config.fish`)**:
  - Custom ASCII Netrunner system telemetry greeting (macOS & Android/Termux compatible)
  - Live theme switcher (`cybertheme netrunner|matrix|synthwave`)
  - Syntax-highlighted `fzf` + `bat` live file previews (`Ctrl+T`)
- **Dual-Line Starship HUD (`starship.toml`)**:
  - Powerline segments with Git diff metrics (`+added -deleted`), Zig/Rust/Python badges, and smart CPU load spike alerts
- **God-Tier Editor & Terminal Engine (`vscode-cyber/`)**:
  - Animated rainbow block caret & typing trail across both Editor and Integrated Terminal
  - Gravity-affected high-WPM spark bursts, `Enter` shockwaves, and `Backspace` laser dissolve
  - Live WPM & Combo Rank HUD (`NETRUNNER` → `OVERCLOCK` → `CYBERPSYCHO` → `GODLIKE`) with Personal Best (PB) tracker
  - Interactive holographic configurator (`Alt+C`) & built-in Breach Protocol hacking mini-game (`Alt+G`)
  - Kiroshi Optics corner reticles, CRT scanlines, parallax grid, and idle Matrix digital rain

## 🚀 Quick Install

```bash
git clone https://github.com/Tony123-tech/dotfiles
cd cyberpunk-dotfiles
./install.sh
```
